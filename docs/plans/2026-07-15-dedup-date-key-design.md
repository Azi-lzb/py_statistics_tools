# 2-5 日期去重键统一设计

## 目标

2-5 按配置去重追加时，去重标识列中的文本日期、Excel 日期和日期时间只按自然日比较。

## 规则

- `2026-01-31`、`2026-01-31 00:00:00`、`2026-01-31 12:30:00` 生成相同去重键 `2026-01-31`。
- Python `date`、`datetime` 以及可识别的日期文本使用同一规则。
- 只改变去重键的比较值，不修改复制到目标工作表的单元格原值。
- 非日期文本和数字沿用当前的去空格字符串比较。
- 规则同时覆盖 2-3 检查重复、2-4 删除重复和 2-5 去重追加，保证三个入口口径一致。

## 验证

用真实 openpyxl 工作表构造源、目标数据，验证文本日期与带时间日期不会重复追加，并验证普通文本不受影响。
